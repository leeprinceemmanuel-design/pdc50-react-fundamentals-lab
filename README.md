# React Fundamentals Practice

1. Install a compatible Node.js version. See https://vite.dev/guide/ if a version warning appears.
2. In this folder, run `npm install` and then `npm run dev`. Open the local URL in the terminal.
3. In `src/App.jsx`, change the file in its import line, for example from `01A.jsx` to `01B.jsx`.
4. Edit that matching file in `src/exercises`. Each file contains a valid placeholder component. Replace the placeholder with your solution.
5. Save and check the browser. Use the handout for the task, expected result, and hint.

Do all three levels within each concept before moving to the next concept. Do not use ShopSmart files in this project.
